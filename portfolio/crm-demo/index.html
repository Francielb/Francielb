    What this preview demonstrates

    Business-to-software thinking, without publishing private code or real customer information.

    The original project's technical focus

    • Python 3.14 / Django 6.1.1
    • PostgreSQL and relational Django ORM models
    • Sales pipeline, interactions and follow-up workflows
    • Dashboard calculations and inactivity rules
    • Automated regression tests in a private pull request

    What this static site is not

    • Not the original Django application or production dashboard
    • Not a live service connected to a customer database
    • Not evidence of real revenue, conversions or productivity gains
    • Not a benchmark, security audit or deployed backend
